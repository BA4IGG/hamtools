为什么做它

山顶架好天线，才发现没带计算器

不是又一个要联网、要看广告的网页工具。所有核心计算与查询数据都在安装包里，打开就能用。

离线优先，联网按需

v2.0 的 21 个工具，算法与数据表全部内置，山里没信号照样算。只有账号登录、QSL 交换与可选的在线数据增强才会访问网络，且失败即退回内置数据。

Material 3 Expressive

内置 Google 官方 HCT 色彩算法源码，9 套配色方案变体、明暗双主题，Android 12+ 还能跟随壁纸动态取色。

数值实算，不靠经验凑

馈线损耗按厂商公布的 7 个频点做双对数插值，链路预算走弗里斯传输方程；源码现有 197 个单元测试按手算标杆值校验。

常用数据表内置

中国与 IARU 三个区的频段划分、约 300 个 DXCC 前缀、Q 简语、摩尔斯对照、业余卫星与国内中继名录，支持区域切换与关键词检索。

账号可选，密码不落明文

呼号 + 密码注册登录，服务端只保存 bcrypt 哈希与可选昵称，JWT 用于保持登录态。不注册也能使用全部本地功能，工具数据始终留在设备上。

完全开源，可自行编译

App 主体采用 MIT 许可，账号服务端源码一并开放、支持自建。引入的 HCT 色彩代码按 Apache License 2.0 保留原始声明。

常见问题

用之前，你可能想问

一定要联网才能用吗？

不需要。v2.0 的 21 个工具，算法与数据表全部打包在 APK 里，飞行模式下也能正常计算与查询；考试练习、SSTV / FT8 编解码同样完全离线工作。只有注册 / 登录账号、QSL 交换、检测更新，以及 DX 集群 / 传播指数 / 呼号查询这几项可选的在线增强才需要网络；在线源失败会自动退回内置数据并如实标注。详见隐私政策。

为什么要申请「修改系统设置」权限？

部分手机厂商会把第三方应用锁在 90Hz。本工具在获得 WRITE_SETTINGS 授权后，会把系统允许的刷新率上限抬到屏幕硬件支持的最高值（最高 120Hz）。这是特殊权限，需要你在系统设置里手动打开；未授权时自动降级，不影响任何计算功能，也不会读取个人信息。

必须注册账号吗？

不必。账号是可选的，不注册也能使用 v2.0 的全部 21 个本地工具；但「QSL 交换」板块涉及双方呼号、通联记录与邮寄地址，必须登录才能使用。注册只需要呼号、密码和可选昵称，不索取手机号、邮箱或真实姓名；QSL 名片中的邮箱与地址由你自愿填写。

QSL 交换会公开我的地址吗？

不会自动公开。台站名录不含邮寄地址与邮箱；只有在你接受某次纸质交换之后，对方才能在该条记录中看到地址。不愿公开可改用 eQSL 电子卡片，或勾选「仅记录到我的交换历史」只做本地留档。全部 QSL 资料、卡片图片与交换记录可随时在应用内一键删除，详见隐私政策。

有业余无线电考试练习吗？

v2.0 已内置 A / B / C 三类题库练习与模拟考试（含艾宾浩斯记忆曲线复习、错题本、组卷 PDF 导出与成绩图表），入口在底部导航正中央，题库与附图全部内置，不登录也能离线练习；登录后可选地把错题本与复习进度同步到账号，服务端只存题号进度与成绩摘要，不存题目正文或所选答案。多选题必须与答案完全一致才得分。题库内容版权归原发布机构所有，本工具仅供离线练习，不保证与实际考试题目完全一致。

计算结果和内置资料能直接照着用吗？

仅供学习与参考。天线尺寸、馈线衰减、链路预算都基于理想模型，实际结果受环境、材料与安装方式影响；频段划分、中继名录等资料可能滞后于主管部门的最新公告。发射前请以现行法规、执照核准范围和实测为准，详见用户协议中的免责条款。

SSTV / FT8 会用到麦克风吗？会保存我的录音吗？

v2.0 中的 SSTV / FT8 编解码在现场收信号解码时需要麦克风，这是唯一会用到麦克风的功能。只有你主动点「申请权限」、看完用途说明并确认后，才会向系统请求；编码、播放、保存 WAV、导入 WAV 解码和本机自测都不需要。采集到的 PCM 只在运行内存里做本机解码，不生成录音文件、不上传、不联网，停止监听或离开页面即释放，因此也没有可供删除的录音。应用不申请位置、相机、通讯录、短信、相册读取等权限，选图与导入导出都走系统文件选择器。详见隐私政策第三条。

会提示我更新吗？

「检测更新」通过 GitHub Releases 只读比对版本：启动后自动检查一次（12 小时内不重复），也能在「关于」页随时手动检查，并可切换正式通道（默认）与测试通道。有新版本时会弹窗列出该版本的更新日志、发布日期与真实数据来源，并提供「前往下载」入口；不会自动下载或安装，是否升级由你自己决定。请求不携带账号或设备信息，失败时会如实区分网络不通、GitHub 限流与该通道暂无发布，详见隐私政策。当前唯一正式 Release 就是 v2.0，正式通道会显示「已是最新版本」，此时仍可点「查看 2.0 发布说明」查阅完整更新日志。

「正式版通道」和「测试版通道」是什么？

GitHub 上 v1.0-beta / v1.1-beta / v1.2 已全部标记为 Pre-release，归入测试版通道；v2.0 是目前唯一的正式版通道 Release。App「关于」页可切换检测更新所跟踪的通道：正式通道（默认）只提示稳定版，测试通道会连预发布一起提示并在弹窗标注「预发布」。切换只影响检测更新，不改变已安装的功能，偏好仅保存在本机；备用源无法确认通道时，弹窗会提示自行到发布页核对。

有广告、统计或推送吗？

没有。应用不接入广告 SDK、第三方统计分析或推送服务。v2.0 的 SSTV / FT8 会按需申请麦克风（见上一条），但依然不申请位置、相机、通讯录、短信、相册读取等权限。Android 13 及以上会在首次进入 QSL 板块时申请通知权限，用于在本机提醒新的交换申请——这不是服务器推送，拒绝后不影响任何交换功能。官网本身是静态页面，不设置 Cookie，主题偏好只保存在浏览器本地。
