一、适用范围与基本原则

1.1 本政策适用于 HAM 工具合集 Android 应用（包名 com.ham.tools）、其配套账号服务（https://api.ba4igg.cn）以及本官网。责任主体为个人开发者 BA4IGG，非公司或机构。

1.2 我们遵循以下原则：最小必要（只收集实现功能所必需的数据）、本地优先（能在设备完成的不上传）、目的限定（不用于广告、画像或营销）、公开透明（收集项与权限在本文逐项列出）。

1.3 若你自行编译客户端或连接自建的账号服务器，则该服务器上的数据处理由该部署者负责，本政策仅描述作者官方提供的服务。

关于麦克风：应用不会录制、保存或上传任何录音文件，也不会在后台或未经你操作的情况下读取麦克风。只有在 SSTV / FT8 工具页里、你已授予 RECORD_AUDIO 并主动点「开始监听」时，才会实时读取一段音频到内存做本机解码；停止监听、解码结束或离开页面即释放麦克风并丢弃缓冲。这段音频不属于「收集的个人信息」，因为它不落盘、不离开设备、也不与你的账号关联。

关于检测更新：应用会向 GitHub 官方接口发起只读请求，但不会把你的呼号、昵称、令牌、偏好、答题记录、QSL 资料或工具输入放进请求，也不携带设备标识符。检测只读取公开的版本信息与更新日志，所选通道仅在本机用于过滤、不会写进请求，不会自动下载或安装任何 APK；有新版本时只弹出说明并提供一个用浏览器打开 GitHub 发布页的入口，是否下载由你自行决定。

账号注册不要求邮箱或手机号，因此我们也无法通过邮件重置密码。请自行保管好密码；忘记密码时请通过第 10 条渠道联系作者处理。

四、信息的使用目的

我们仅将收集到的信息用于以下目的，不会超出范围使用：

  • 创建与识别账号：校验呼号格式与唯一性、以 bcrypt 校验密码；
  • 维持登录状态：签发与验证 JWT，App 冷启动时调用 /api/auth/me 恢复登录态；
  • 展示账号信息：在「我的」页显示呼号、昵称及由呼号推算的所属分区；
  • 保存你的界面偏好：主题、配色等设置只存本地；
  • 设备显示优化：读取刷新率上限并在授权后调整系统设置；
  • 完成 QSL 卡片交换：保存你的名片与卡片图片、按呼号查找已开放交换的台站、记录每次通联与交换状态、在你接受后向对方提供联系信息、生成交换历史与统计；
  • 发送交换申请提醒：在你授权通知权限后，把新申请以本机通知的方式告诉你；
  • 保障服务安全：通过访问日志排查异常请求、暴力尝试与服务故障。

我们不会将你的数据用于用户画像、个性化广告、精准营销、自动化决策，也不会出售或出租给任何第三方。

五、本地存储与设备数据

5.1 应用偏好与登录令牌保存在 Android 应用私有目录的 DataStore Preferences 中，其他应用无法读取；退出登录会清除本地令牌，卸载应用会删除这些私有数据。

5.2 应用开启了 Android 系统备份（allowBackup），因此系统或厂商提供的云备份服务可能包含上述偏好数据。你可以在设备的「系统设置 → 备份」中关闭应用数据备份或删除已有备份，这部分由你的设备厂商 / 系统管理。

5.3 计算与查询所依赖的数据表（频段划分、呼号前缀、Q 简语、摩尔斯、卫星与中继）随 APK 内置，属于应用资源，不含任何与你个人相关的数据。

5.4 高刷优化读取与写入的是设备显示相关的系统设置，不会读取你的联系人、文件、位置或账号信息。

5.5 「考试练习」板块（v2.0 正式版已包含）的官方题库与附图同样随 APK 内置。你的答题选择、对错结果、艾宾浩斯复习进度、错题本与成绩摘要只写入应用私有目录；登录后可选地把仅题号进度、复习数字与成绩摘要同步到账号，题目正文、所选答案与个人资料不上传。学习记录不用于画像，可在板块内一键清空，卸载应用也会一并删除。该板块本身不使用麦克风等任何新权限。

5.6 「SSTV / FT8 编解码」不产生任何持久化录音：麦克风 PCM 只存在于运行内存的滚动缓冲中，停止监听或离开页面即丢弃；FT8 消息文本、SSTV 待编码图片与解码图像都不会写进应用私有目录、不会关联账号。你主动导出的 WAV / PNG 由你通过系统文件选择器指定保存位置，之后由你自行管理，应用不再读取。

5.7 「检测更新」只在设备本地保存四个与版本有关的偏好：上次检测时间（用于 12 小时节流）、你点过「跳过此版本」的 tag、上次成功看到的最新版本号、所选发布通道（正式 / 测试）。它们写在同一个 DataStore 里，不含任何个人信息，不关联账号、不上传；卸载应用即删除。检测到的 Release 更新日志只在本次运行中显示，不落盘、不缓存。

六、服务端访问日志

6.1 当你使用账号功能时，承载服务的 Web 服务器 / 反向代理会按常规运维配置生成访问日志，通常包含 IP 地址、请求时间、请求路径、User-Agent 与响应状态码。这是任何 HTTP 服务都会产生的技术记录。

6.2 这些日志仅用于排查故障、识别异常流量与保障基本安全，不用于用户画像、行为分析或营销，也不会与第三方分析平台共享。

6.3 应用不会在请求中夹带设备标识符、广告 ID 或工具输入内容；登录接口的请求体只包含呼号与密码（密码经 HTTPS 传输后仅用于 bcrypt 校验，不写入日志）。

6.4 「检测更新」访问的是 GitHub（第三方服务），不是作者自建的账号服务器。作者无法读取、也无法删除 GitHub 侧按自身政策生成的访问记录；读取的是公开的 Release 列表，通道选择只保存在本机、不会随请求发送，该请求不含账号与个人信息，若你希望完全不产生这类记录，可在系统设置中限制本应用的网络访问，检测会如实提示「无法连接 GitHub」，其余本机功能不受影响。

7.1 数据存储于作者租用的服务器所在地区。若未来更换托管地区或增加数据处理者，我们会在本政策中更新说明。

7.2 当账号服务终止时，我们将在可行范围内删除或匿名化服务端账号数据，并通过官网或仓库公告说明。

八、共享、转让与公开披露

8.1 我们不会出售、出租或与第三方共享你的个人信息用于商业目的。应用内不嵌入任何第三方广告、统计、崩溃上报或推送 SDK。

8.2 以下情形可能涉及数据提供，且以最小必要为限：

  • 为完成网络传输所必需的托管服务商、域名与 CDN 服务（其接触范围限于传输过程与访问日志）；
  • 依据法律法规、司法机关或主管机关的强制要求；
  • 为保护作者或他人合法权益，在必要范围内处理欺诈、攻击或滥用行为。

8.3 项目源码在 GitHub 公开发布，但仓库中不包含任何用户账号数据、QSL 卡片图片或访问日志（上传目录已被忽略）。请勿在公开 Issue 中粘贴密码、令牌、邮寄地址或其他敏感信息。

8.4 若本项目未来整体转让给其他维护者，我们会提前公告，并确保接收方继续受本政策约束或重新取得你的同意。

九、数据安全

9.1 我们采取的措施包括：账号通信强制走 HTTPS；密码使用 bcrypt 加盐哈希存储，服务端不保存明文；鉴权采用带有效期的 JWT；服务端按最小字段返回用户信息；应用不请求与功能无关的权限。

9.2 针对 QSL 交换：所有 QSL 接口都要求登录；邮寄地址与邮箱不出现在名录等列表接口，只在交换被接受后由双方按单条记录查询；卡片图片按文件头白名单校验后存入非公开目录，并需逐个鉴权下载；服务端按账号关联清理，删除资料时同步移除图片文件与交换记录。

9.3 请理解，互联网传输与任何软件都不存在绝对安全。纸质 QSL 交换会向对方公开收件地址，请你自行判断是否愿意披露，也可改用 eQSL 电子卡片或只填写到城市级别的 QTH；同时建议为账号设置独立且足够长的密码，不要与其他站点复用，并妥善保管设备。

9.4 若发生可能影响你权益的数据安全事件，我们会通过官网公告与 GitHub 仓库及时说明事件概况、可能影响与补救措施，并按法律要求向有关部门报告。

十、您的权利与账号删除

在适用法律允许的范围内，你可以行使以下权利：

  • 访问与更正：在应用「我的」页查看呼号与昵称，并可直接修改昵称；
  • 修改密码：在登录后通过修改密码功能更新（需验证原密码）；
  • 退出登录：清除设备本地的 JWT 令牌，账号服务端数据仍保留，之后可重新登录；
  • 停止使用：卸载应用将删除应用私有目录中的偏好与令牌；
  • 删除 QSL 资料：在应用「QSL 交换 → 我的资料 → 数据管理」中，可一键删除服务端的 QSL 名片、全部卡片图片与交换记录（不可恢复，但不删除登录账号本身）；
  • 关闭通知：随时在 Android 系统设置 → 应用通知中关闭，或首次弹窗时选择「暂不开启」；
  • 关闭麦克风：随时在 Android 系统设置 → 应用权限 → 麦克风中关闭，或首次用途说明里选「暂不」；关闭后编码、播放、导入 WAV 与本机自测仍可用。由于应用不保存录音，本地没有可供删除的音频文件；
  • 删除账号数据：当前版本没有应用内自助注销入口。请通过 GitHub Issues 提交申请，标题注明「隐私请求 - 删除账号」，并提供需删除的呼号；为防冒删，作者可能要求你用该账号能证明的方式作简单核验。核验通过后，我们将删除服务端的呼号、昵称、密码哈希、QSL 名片、卡片图片与全部交换记录，并回复确认，通常在 15 个工作日内处理完毕。

10.1 删除账号后，已签发的 JWT 在有效期内仍可能通过签名校验，但服务端已无对应账号记录，登录态随即失效；你也可以在应用内先退出登录以立即清除本地令牌。

10.2 依法必须留存的技术日志或备份副本将在轮转周期内清除，不会再用于其他目的。

10.3 若你对处理结果有异议，可在原 Issue 中补充说明，或依据用户协议第十一条寻求进一步解决。

十一、未成年人保护

11.1 本工具面向业余无线电爱好者，相关操作依法需要取得相应资格与执照，主要使用者为成年人。我们不故意收集儿童个人信息。

11.2 未满 14 周岁的儿童使用本工具或注册账号，须事先取得父母或其他监护人的同意；监护人可随时通过第 10 条渠道要求查看或删除相关信息。

11.3 若我们发现未满 14 周岁儿童在未经监护人同意的情况下提供了个人信息，将尽快删除相关数据。
